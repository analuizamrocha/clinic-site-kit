# Compliance doc template

Fill this into the destination repo as `docs/compliance-guidelines.md`. The
**section headings are fixed** — downstream skills reference them by name. The
content is entirely jurisdiction-specific.

## Notes for whoever fills this

- An empty §10 means the research wasn't thorough enough. Every real jurisdiction
  has ambiguity.
- §4 is where profession-to-profession differences concentrate. Spend your
  research budget there.
- Write §8 so a non-lawyer reviewer can run it in five minutes. That's the
  section that actually gets used on every publish.
- If two professions share the clinic, the stricter rule governs shared surfaces
  — state that at the top of §3.
